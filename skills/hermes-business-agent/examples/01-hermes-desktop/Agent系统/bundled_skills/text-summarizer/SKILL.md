# 文本摘要

## 何时使用
当用户给出一段较长的文本（文章、报告、聊天记录、网页正文）并要求「总结 / 概括 / 提炼要点」时使用。

## 做法
1. 通读全文，识别主题句与支撑论据。
2. 输出 3-7 条要点，保留关键数字、人名、结论。
3. 如原文有明确要求（如「给老板看」「限 50 字」），按场景调整语气与长度。
4. 不确定处标注「需确认」，不要编造事实。

## 输出格式
- 用无序列表呈现要点。
- 先给一句话总括，再列要点。
- 中文输出；专有名词保留原文。
