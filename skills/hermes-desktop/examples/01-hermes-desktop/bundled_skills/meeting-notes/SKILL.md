# 会议纪要整理

## 何时使用
当用户贴入一段会议记录、群聊讨论或语音转写，并要求「整理成纪要 / 待办 / action items」时使用。

## 做法
1. 区分「讨论」与「决议」：只有明确达成一致的才算结论。
2. 提取待办事项，每条包含：事项、负责人（若提及）、截止时间（若提及）。
3. 标记「未决 / 待确认」事项，不要替用户拍板。
4. 用表格呈现待办，便于直接复制进任务系统。

## 输出格式
- 一段 2-3 句的背景总结。
- 「决议」小节：要点列表。
- 「待办」小节：表格（事项 | 负责人 | 截止 | 状态）。
- 中文输出。
